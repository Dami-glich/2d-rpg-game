# Urban Outlaw RPG

A browser-based 2D top-down RPG prototype set in a city world.

Features:
- Player movement with WASD / arrow keys
- City map with houses, apartments, cars, river, casino, and admin district
- Faction zones and district mission progression
- Enemy encounters and combat
- NPC interaction and rewards
- Health, cash, and reputation HUD

How to run:
1. Open the project folder in a local web server.
2. Start a simple static server from the project root, for example:
   python -m http.server 8000
3. Open http://localhost:8000 in your browser.

Controls:
- WASD / Arrow Keys: move
- F: attack
- E: interact with NPCs
- H: use medkit

This is a playable starter prototype meant to be expanded into a larger RPG world.
